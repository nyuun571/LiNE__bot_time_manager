# LINE Bot 時間割・タスク管理 (Time Manager)

LINEとGoogle Spreadsheetを連携させた、学生・社会人向けのLINE Botアプリケーションです。
LINEのトーク画面から簡単に時間割やタスクを登録・確認できるほか、授業の時間に合わせて自動でプッシュ通知を送ることができます。データベースとしてGoogle Spreadsheetを活用しており、Vercelでの運用を前提とした構成になっています。

## ✨ 機能 (Features)

- **時間割の登録・編集**
  LINEのメッセージから特定の曜日・時限の授業を直感的に登録できます。
- **時間割の確認**
  「月」と送れば月曜日の時間割一覧を、「月 1」と送ればその時間の授業内容のみをサクッと確認できます。
- **自動リマインド通知 (プッシュ配信)**
  `cron.py` を定期実行することで、各時限の開始時刻（1限: 08:50〜, 2限: 10:35〜...）に合わせてLINEへリマインド通知を送信します。
- **Google Spreadsheet連携**
  ユーザーがBotをフォローした際に自動で専用のシート（タブ）を作成し、アンフォロー時には自動で削除します。
- **iPhoneショートカット対応**
  Raspberry Pi等でのcron実行環境がなくても、iPhoneの「ショートカット」アプリとオートメーション機能を使うことで、同様の時間割通知を実現可能です。

## 📱 使い方 (Usage)

Botを友だち追加（フォロー）すると、Googleスプレッドシート上にあなたの専用シートが自動作成されます。以降、以下のフォーマットでメッセージを送信してください。

### 1. 時間割を登録・編集する
`編集 [曜日] [時限] [内容]` の形式で送信します。
> 例：`編集 月 1 微分積分`
> 例：`編集 木 3 プログラミング演習`

### 2. 時間割を確認する
- **その曜日の時間割をすべて確認**
  `[曜日]` のみ送信します。
  > 例：`月`
- **特定の授業だけを確認**
  `[曜日] [時限]` の形式で送信します。
  > 例：`月 1`

## 🛠 技術スタック (Tech Stack)

- **言語**: Python 3.12
- **Webフレームワーク**: Flask 3.1.1
- **インフラ・ホスティング**: Vercel (Serverless Functions)
- **パッケージ管理**: Poetry / pip
- **API・外部連携 (Integrations)**: 
  - **LINE Messaging API**: Webhook処理、Reply/Pushメッセージ配信
  - **Google Sheets API / Google Drive API**: `gspread` を使用したスプレッドシートの操作・管理
  - **Apple Shortcuts (iPhoneショートカット)**: クライアント側での自動化トリガーおよびWebリクエスト送信
